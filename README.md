# pc-system-cleaner
This software clear your Recycle bin, Dump files, Prefetch files, Logs files, and Restart Windows explorer for better refreshment.

## Setup Guide
  - 1st make a .txt file on your computer and put this code then press 'Ctrl+Shift+S' then remove the '.txt' extention and put '.bat' and then save the file.
  - Now press 'Windows+R' and write input 'shell:startup' then click Enter. A new window will be open.
  - Now copy your '.bat' file you create it before, then past on this New Window. then Shut Down your PC and Power on again, you will se your system cleaner window when you power on your computer and ask admin permission for start cleaning.
  - Enjoy......
